# Client site template

Independent Next.js App Router starter generated by `pnpm create:site`.

## Configure

1. Set `site.canonicalUrl` in `project.config.ts` before a production build.
2. Copy `.env.example` to `.env.local` if you need `NEXT_PUBLIC_SITE_URL` for deploys.
3. Replace the Home and Work routes with project content. They are architecture specimens.

## Styleguide

`/styleguide` documents this project's tokens, type, components, and motion. It is a development tool: it stays out of the public nav, ships with `noindex, nofollow`, and returns 404 in production unless `ENABLE_STYLEGUIDE=true`.

Customize it through `app/tokens.css` and `project.config.ts`. Specimen copy lives in `app/styleguide/_data/styleguide-data.ts`.

## Scripts

- `pnpm dev`
- `pnpm typecheck`
- `pnpm test`
- `pnpm build`

Do not invent company, CMS, or analytics vendors. Keep flags in `project.config.ts` until a real integration exists.
